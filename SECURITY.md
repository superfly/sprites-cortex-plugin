# Security policy

Do not report security vulnerabilities in a public issue.

Use the private reporting instructions at [Fly.io Security](https://fly.io/security/) and identify this project as `superfly/sprites-cortex-plugin`. Include reproduction steps, affected versions, and whether the issue concerns plugin instructions, OAuth, hooks, or the hosted Sprites MCP server.

This plugin intentionally stores no Sprites or Snowflake credentials. Cortex Code owns the OAuth credential flow and storage. Never attach access tokens, browser cookies, Snowflake connection files, or production data to a report.
