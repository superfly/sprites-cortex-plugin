# Support

## Plugin bugs

Use the repository's [bug report form](https://github.com/superfly/sprites-cortex-plugin/issues/new?template=bug_report.yml) for reproducible problems with installation, OAuth configuration, commands, skills, agents, hooks, or CI validation.

Include the plugin version, `cortex --version`, operating system, relevant redacted output, and the smallest reproduction. Never include credentials, organization tokens, browser cookies, Snowflake connection files, or production data.

## Product questions

- Sprites usage and MCP behavior: [Sprites documentation](https://docs.sprites.dev/) and the [Fly.io community](https://community.fly.io/).
- Cortex Code behavior: [Snowflake Cortex Code documentation](https://docs.snowflake.com/en/user-guide/cortex-code/cortex-code).
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md), not the public issue tracker.

This repository's issue tracker is not a channel for account, billing, or production-incident support. See [Fly.io support options](https://fly.io/docs/about/support/) for those requests.
